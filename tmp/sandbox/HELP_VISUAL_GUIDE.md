## 🎯 User Journey Map

```
START: User needs help
  │
  ├─ Option 1: Click "Help & Support" in header
  │      ↓
  │   Lands on /help
  │      ↓
  │   Sees animated bot welcome
  │      ↓
  │   Chooses quick action OR types question
  │      ↓
  │   Receives AI response + voice
  │      ↓
  │   RESOLUTION or ask follow-up
  │
  ├─ Option 2: Browse quick actions
  │      ↓
  │   Click pre-made question
  │      ↓
  │   Instant response
  │      ↓
  │   RESOLUTION
  │
  └─ Option 3: Need human support
         ↓
      See contact info in sidebar
         ↓
      Email or call support
         ↓
      RESOLUTION (24 hours)
```
